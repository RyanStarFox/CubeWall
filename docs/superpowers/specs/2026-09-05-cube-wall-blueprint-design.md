# 魔方墙图纸生成工具

日期：2026-09-05  
状态：待用户确认

## 目标

本地网页工具：上传一张图片，把它量化成魔方贴纸颜色，按所选魔方阶数分块，生成可预览、可改色、可下载、可打印的拼装图纸。

图片始终只在浏览器内处理，不上传到服务器。

## 用户流程

1. 打开页面，拖入或选择一张图片。
2. 选择魔方类型（默认 3×3）。宽、高以贴纸像素计，自动对齐到阶数 N 的倍数；同时显示魔方列数 × 行数。
3. 可选：选择比例不符时的处理（默认补白）；调整抖动强度（默认 0%）。
4. 预览实时更新：细线是贴纸，每 N 格一条粗线是一个魔方，每块有编号。
5. 在调色板选中一种颜色作为画笔，用四种工具手动改图纸；可随时撤销重做。
6. 查看六色贴纸用量；需要时下载 PNG 或打印。

## 架构

单页前端，无后端。

- 构建：Vite + TypeScript（原生 DOM，不引入 React）。
- 图像：浏览器 `Canvas` / `OffscreenCanvas` 读取、缩放、取色。
- 状态：内存中的网格 `ColorId[][]`（0–5）+ 当前设置；自定义颜色写入 `localStorage`。
- 导出：把预览画到 canvas 生成 PNG；打印走浏览器打印样式。

职责边界：

| 模块 | 职责 |
|---|---|
| `image-load` | 读文件为 `ImageBitmap`，校验类型 |
| `quantize` | 缩放到 W×H，明度加权 Lab 最近色，线性光空间 Floyd–Steinberg 抖动 |
| `grid` | 网格数据、四种上色工具、撤销栈、用量统计 |
| `palette` | 默认 6 色、自定义、读写 localStorage |
| `render` | 预览绘制：格子填充、细/粗网格、魔方编号 |
| `export` | PNG 下载；打印布局（图例 + 用量 + 编号图纸） |
| `ui` | 绑定控件、拖放、尺寸对齐、比例锁定 |

## 魔方类型与尺寸

- 预设：2×2、3×3（默认）、4×4、5×5。
- 自定义：N×N，N 为整数，范围 2–7。
- 贴纸宽 `W`、贴纸高 `H` 必须是 N 的倍数；用户改数字后对齐到最近的合法倍数（最小为 N，即至少 1 个魔方；距离相等时向上取）。
- 默认尺寸：10×10 颗魔方，即三阶下 30×30 贴纸。换阶数 N 时，若用户没手动改过尺寸，保持 10×10 颗魔方（宽高 = 10N）；用户手动改过就保留其魔方数、只按新 N 换算贴纸数。
- 载入图片不改变尺寸（「按原图比例」模式除外），只按当前宽高重新量化。

## 比例不符时的处理

图片宽高比与网格宽高比不一致时，由「比例不符时」三选一决定，默认补白（不丢画面内容）：

| 模式 | 行为 |
|---|---|
| 裁切 | 填满网格，原图超出的部分切掉（`scale = max`，居中） |
| 补白 | 整图放进网格，比例不符的一侧留边框（`scale = min`，居中） |
| 按原图比例 | 不裁不留边，改网格尺寸去迁就原图：以宽为准算高，再对齐到 N |

补白颜色单独用下拉选择，默认白色。补白区域在量化完成后**直接写死**成该颜色，不交给抖动处理——否则误差扩散会在纯色边框上撒出杂点。
- 魔方列数 = W / N，行数 = H / N。
- 「按原图比例」模式下：改一边，另一边按原图像素比计算后再对齐到 N 的倍数；换阶数、换图时同样重算。
- 单边超过 300 贴纸时弹出警告，仍允许生成。

## 颜色

默认（可恢复）：

| 名称 | 色值 |
|---|---|
| 白 | `#FFFFFF` |
| 黄 | `#FFD500` |
| 蓝 | `#0051BA` |
| 绿 | `#009E60` |
| 红 | `#C41E3A` |
| 橙 | `#FF5800` |

- 用户可改这 6 个色值；改动立即用于映射与预览。
- 持久化 key：`cubewall.palette.v1`，存 `{ colors: string[6] }`。缺省或损坏则用默认色。
- 不增加第 7 色，不删除颜色。名称固定为白黄蓝绿红橙，仅色值可变。

## 量化规则

1. 原图按 `W×H` 缩放（canvas drawImage，平滑缩放）。
2. 每个贴纸像素转到 Lab，与当前 6 色比距离，取最近者。距离对明度 L 加权 1.5 倍：调色板里没有黑色，暗部按亮度就近（落到蓝）比按色相就近（落到红）更接近原图观感。权重实测上限就是 1.5，再高会把暗橙也推成红色。
3. 抖动为 0–100% 可调滑块，默认 0%（纯最近色，边界干净；照片想要层次可调到 40–60%）。Floyd–Steinberg 误差扩散**在线性光空间**进行——远看这面墙时人眼平均的是光量而非 sRGB 数值；在 gamma 空间扩散会让暗部误差被夸大，把暗色区域推成红色。累积误差截断在 [-0.6, 1.6]，防止高反差处误差滚雪球。0% 即纯最近色。
4. 透明/半透明像素按不透明处理（画到白底上再取样）。
5. **不**求解真实魔方可还原性：每个 N×N 只是图纸分块，不保证能在一颗实体魔方上拧出。

重新量化的时机：换图、改尺寸、改阶数、改调色板、改抖动强度。点击改色后的手工格子，在下一次重新量化时被覆盖（不单独做「保护编辑」）。

## 预览与点击改色

- 格子填对应颜色；贴纸间 1px 细线；每 N 格 2px 粗线。
- 魔方编号：行用从 1 起的数字，列用 A、B、C…（超过 Z 后为 AA）。格式 `行-列`，如 `1-A`。编号画在该魔方块左上角或中心，保证打印时仍可读。
- 未选图片时预览为空状态，提示拖入图片。

## 手动上色

调色板当前选中色即画笔（进入页面默认白色）。色块上半部分点击选画笔，下方细色条改色值——两者必须是不重叠的点击区域，否则透明的取色器会盖住色块导致选不中画笔。

四种工具：

| 工具 | 行为 |
|---|---|
| 画笔 | 按住拖动连续涂抹。相邻两次指针事件之间补一条直线，避免快速拖动漏格 |
| 矩形 | 按住拖出选区，拖动时半透明预览，松开填充 |
| 油漆桶 | 填充与点击处四邻相连的同色区域（显式栈，不用递归） |
| 同色全换 | 全图所有该颜色的格子一次换掉 |

撤销/重做：每次操作前存整张网格快照（每格 1 字节，300×300 也只有 90KB，比记录增量简单且不会漏记），上限 60 步。⌘Z / ⌘⇧Z 及按钮均可触发。没有产生实际改动的点击不占用撤销步数。重新量化会清空历史，因为旧快照与新网格对不上。

## 图纸导出

PNG 与打印包含同一套信息：

- 网格图纸（颜色 + 细/粗线 + 编号）
- 六色图例（名称 + 色块）
- 各颜色贴纸数量，以及魔方总数（列 × 行）
- 页眉：W×H 贴纸、N×N、图片名（若有）

打印：`@media print` 隐藏控制栏，图纸分页时尽量按魔方行断开（尽力而为，不强制完美分页）。

下载文件名：`cubewall-{W}x{H}-n{N}.png`。

## 异常

- 非图片文件：提示「请选择图片文件」。
- 未上传就下载/打印：提示「请先上传图片」。
- localStorage 不可用：自定义色仅当前会话有效，不打断主流程。

## 明确不做

- 后端、账号、云同步、历史方案。
- 真实魔方合法性求解 / 拧法。
- PDF 专用引擎（打印即出纸）。
- 选区的移动/复制/旋转（只做填充，不做选区搬运）。

## 验证

- 上传照片，3×3，约 30×30 贴纸：预览分块正确，用量之和 = W×H。
- 改为 2×2 / 自定义 4：粗线间隔与魔方数跟着变，宽高被对齐。
- 改橙色并刷新页面：橙色保持自定义值。
- 比例模式（3:1 的三色宽图，30×30）：裁切 → 900 格全是中段色；补白 → 图像 300 格 + 边框 600 格；换边框色 → 边框 600 格跟着变；按原图比例 → 尺寸变 30×9，三色各 90 格。
- 上色工具（30×30，左白右绿图）：画笔横拖 8 格 → 红 8；矩形 6×6 → 红 +36；油漆桶点绿区 → 只填相连的 26 格；同色全换点白格 → 白 0。
- 撤销三次精确回到初始用量，重做三次恢复。
- 再改尺寸：网格按新量化结果重置。
- 下载 PNG 能打开；打印预览只有图纸、图例、用量，没有侧栏。
